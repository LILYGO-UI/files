# LILYGO UI Files 界面规范

本文是 `lilygo-ui-files` 的项目级 UI 规范。修改页面、组件、布局、样式、文案、
字体或渲染测试时，必须同时遵守模板仓库中的 `docs/01-user-interface.md`；当本文
没有另行收窄产品行为时，以模板规范为准。

## 页面与用户流程

应用通过 Files 页面呈现文件管理状态，并提供独立的 Help 页面。Files 页面由同一份业务状态
呈现以下可达界面；尺寸变化只重新应用布局，不得重建 ViewModel 或清空用户状态。

### 根目录

- 导航栏显示居中的“Files”标题和右侧圆形更多操作按钮，左侧保留等宽占位使标题
  居中；下方依次为搜索入口和文件图标网格或列表，不显示存储使用情况；
- 文件夹始终排在文件之前；默认按名称升序排列，名称比较不区分大小写；
- 隐藏项目不显示；空目录和目录读取失败必须显示明确状态；
- 内容下方居中显示当前目录的条目数量；
- 点击普通文件夹进入该目录，点击文件进入只读预览；长按文件或文件夹弹出上下文菜单，
  抬起手指时不得再打开该项目。

### 子目录

- 导航栏显示左侧圆形返回按钮、居中的当前目录名称、作为副标题的相对根目录路径
  和右侧圆形更多操作按钮；下方为搜索入口和文件图标网格或列表；
- 返回操作逐级回到父目录，但不能越过配置的文件根目录；
- 很长的目录名和路径必须换行、截断或在自己的区域内滚动，不得挤压主要操作。

### 搜索

- 与 iOS 搜索模式一致，输入框取代导航栏标题，与圆形返回按钮位于同一行；结果
  数量和当前路径显示在其下方，结果使用与目录相同的显示方式；
- 搜索范围仅为当前目录，不递归扫描；
- 输入变化通过 ViewModel 更新查询和结果数量；
- 点击搜索结果沿用文件夹导航或文件预览规则；
- 无结果时显示空状态，搜索文字在横竖屏切换后保持不变；
- 屏幕键盘出现时，输入框、结果列表和退出搜索的操作必须仍然可达。

### 键盘操作

目录内容和搜索结果可以使用物理键盘浏览。方向键只在当前目录或搜索结果中的文件、文件夹
之间移动焦点，不会把焦点移到导航、搜索或菜单控件，也不会因为焦点变化而打开项目；焦点
移动到屏幕外的项目时，所属网格或列表应滚动到该项目并保持其可见。到达项目集合边界时，
焦点仍留在文件或文件夹项目集合内。

- 在图标视图中，左、右方向键移动到前一个或后一个项目；上、下方向键按当前网格列数
  跨越一整行，尽量保持原列，超出边界时停在该方向的首个或末个项目；
- 在列表视图中，上、下方向键移动到前一行或后一行，左、右方向键也按列表顺序移动到
  前一个或后一个项目；
- 短按 `Enter` 对当前目录项目执行普通点击规则：文件夹进入该目录，文件打开只读预览。
  在选择模式中，短按 `Enter` 只切换当前项目的选中状态，不打开项目；
- 长按 `Enter` 只对当前目录中的项目打开与触摸长按相同的详细操作菜单。长按触发后，释放
  `Enter` 不得再次打开或切换该项目；搜索结果和选择模式中的长按仍不打开详细操作菜单；
- `Tab` 在当前页面中可聚焦控件之间移动，焦点顺序必须覆盖导航按钮、搜索入口、菜单项、
  项目和对话框操作，并跳过隐藏或禁用控件；搜索输入框接收键盘字符和退格键并实时刷新
  结果；搜索结果沿用目录项目的方向键、`Enter` 和长按规则；
- “更多”或文件操作菜单打开时按 `Esc` 只关闭菜单并回到当前目录，应用继续运行；
- 键盘输入导致内容滚动或屏幕尺寸变化时，查询文字、焦点和当前滚动位置必须保留，搜索
  输入框、结果和退出搜索的操作仍须可达。

### 图标视图

目录内容和搜索结果默认参考 iOS“文件”应用的图标视图：

- 每个单元格自上而下为图标、名称和灰色详情，整个单元格是一个可点击按钮，按下时
  显示圆角高亮；
- 名称居中，最多两行，超出部分以省略号截断，不得把详情挤出单元格；
- 文件夹详情显示条目数量（“1 item”或“N items”，隐藏项目不计）；无法读取该目录
  时显示“Folder”；
- 文件详情依次显示本地修改日期（`YYYY/M/D`）和文件大小；符号链接以“Symbolic
  link”代替大小；
- 文件夹使用 iOS 风格文件夹图标；文件使用带右上折角的文档页，底部显示不超过 4 个
  字符的大写扩展名，文本和 PDF 显示缩略文字线，音频显示音乐徽标；
- 列数由网格可用宽度决定：单元格最小宽度 160 px、列间距 16 px，至少 2 列、至多
  8 列。`568x1232` 为 3 列，`1232x568` 为 6 列，`320x568` 为 2 列。

### 列表视图

在更多操作菜单中选择“List”后，目录内容和搜索结果参考 iOS“文件”应用的列表视图：

- 每行高 80 px、占满内容宽度，整行是一个可点击按钮；
- 自左向右为前导列、56 px 高的小图标和文字列；文件夹的前导列显示蓝色右箭头，表示
  点击进入该目录，文件的前导列留空以保持对齐；
- 文字列上行为单行文件名，下行为“修改日期 - 大小”或“修改日期 - 条目数量”，超出
  部分以省略号截断；
- 分隔线从文字列起始处绘制，不贯穿图标；
- 小图标只保留 2 条缩略文字线；音频文件只显示音乐徽标，不再叠加类型标签。

### 排序

- 排序方式为名称、种类（扩展名）、日期和大小；任何排序下文件夹都排在文件之前，
  同值项目按名称排列；
- 名称和种类默认升序，日期和大小默认降序（最新、最大在前）；文件夹按条目数量参与
  大小排序；
- 再次选择当前排序方式会切换升序和降序；
- 排序和显示方式在本次运行期间对所有目录生效，切换排序会清除当前选择。

### 选择模式

- 从更多操作菜单的“Select”进入；导航栏左侧为“Select All”胶囊按钮，全部选中后
  变为“Deselect All”；标题为“Select Items”或“N Selected”；右侧为深色圆形完成
  按钮；
- 选择模式下点击项目只切换选中状态，不打开文件夹或文件；选中项目显示浅蓝背景和
  蓝色对勾圆环，未选中项目显示灰色圆环；
- 图标视图的圆环位于图标右下角并保持在图标区域内，列表视图的圆环位于前导列；
- 选中状态在原有对象上更新，不重建页面，选择模式内的内容滚动位置保持不变；
- 搜索框保持显示但不可用，避免内容位移；
- 点击完成按钮退出选择模式并清除选择，目录内容回到顶部，确保搜索框完整可见；
- 内容下方固定显示 iOS 风格选择工具栏：左侧白色胶囊内依次为“Duplicate”“Move”
  “Delete”三个图标按钮，右侧为圆形更多按钮；工具栏不随内容滚动，内容区在其上方
  结束。未选中任何项目时四个按钮均禁用并以辅助文字色显示。不显示“共享”；
- “Duplicate”为每个所选项目在原目录创建带编号的副本；“Move”打开移动页，“Delete”
  打开删除确认提示框，二者都作用于全部所选项目；
- 工具栏命令失败时保持选择模式和选中项目，并在导航栏下方以危险色说明原因；再次
  改变选择后说明消失。

### 选择菜单

选择工具栏的更多按钮打开参考 iOS 的菜单，不显示“标签”：

- 菜单为宽度不超过 340 px 的白色圆角卡片，右边缘与更多按钮对齐，显示在工具栏
  上方，高度超过可用空间时在菜单内滚动；不使用暗色遮罩，下方仍显示选择模式；
- 菜单自上而下为“Copy N Items”“New Folder with N Items”和“Compress”，每行依次为
  符号和标题，N 为所选项目数量（1 个时为“1 Item”）；
- “Copy”把所选项目全部放入剪贴板，之后可在更多操作菜单中一起粘贴；“New Folder
  with N Items”在当前目录创建“New Folder”（重名时追加编号）并把所选项目全部移入，
  随即打开该文件夹的“Rename”提示框；“Compress”把单个项目压缩为“名称.zip”，把多个
  项目一起压缩为“Archive.zip”（重名时追加编号）；
- 点击菜单外区域关闭菜单并回到选择模式，所选项目保持不变；命令失败时菜单保持打开，
  并在顶部以危险色说明原因。

所选项目的命令成功后退出选择模式并刷新当前内容；从选择模式打开的移动页和删除确认
提示框取消后回到选择模式，所选项目和内容滚动位置保持不变。

### 文本预览

- 预览是只读界面，导航栏显示文件名并以副标题显示“修改日期 - 大小”，正文区显示
  类型标签、文件名和文本内容；
- 文档容器使用 `LV_SIZE_CONTENT` 或等价的内容驱动尺寸，长文本由外层容器滚动；
- 预览最多显示 8 KiB，截断时必须显示 `[Preview truncated]`；
- 不支持的文件类型显示明确说明，不呈现不存在的编辑、分享或文件管理操作；
- 文件名、元数据和正文均不得与导航区重叠或越出页面。

### 新建文件夹

- 从更多操作菜单进入 iOS 风格提示框，输入目标文件夹名称后创建在当前目录；
- 提示框只提供“取消”和“创建”两项明确操作，两者均为胶囊按钮；
- 空名称、`.`、`..`、包含 `/`、路径过长、重名或权限错误必须保留当前输入并
  显示可理解的错误；
- 创建成功后关闭模态框、刷新当前内容，并保持用户仍位于原目录。

### 上下文菜单

在根目录或子目录中长按项目时，参考 iOS“文件”应用弹出上下文菜单；搜索结果和选择
模式中的长按不弹出菜单。

- 页面覆盖 30% 黑色模态遮罩；被长按的项目以白色圆角卡片和柔和投影原位“抬起”，
  与原单元格或列表行完全重合，项目被部分遮挡时先滚动到完全可见；
- 菜单为宽度不超过 340 px 的白色圆角卡片，优先显示在项目下方，其次上方；高度都
  放不下时（例如横屏）显示在项目左侧或右侧；紧凑屏幕上仍放不下时菜单可以覆盖抬起
  的项目，高度超过可用空间时在菜单内滚动；
- 菜单自上而下为：并排的“Copy”和“Move”两个图标按钮；分隔线；“Get Info”
  “Rename”“Compress”“Duplicate”“New Folder with 1 Item”；分隔线；以危险色显示
  的“Delete”。不显示“共享”“自定义文件夹与标签”和“收藏”；
- 每行依次为符号和最多两行的标题，行高至少 48 px；
- 点击菜单外区域或抬起的项目关闭菜单且不改变状态；“Copy”“Compress”“Duplicate”
  执行后关闭菜单并刷新当前内容；命令失败时菜单保持打开，并在顶部以危险色说明原因；
- 尺寸变化后菜单和抬起的项目在新布局完成后重新定位，不重建页面。

### 简介

“Get Info”打开参考 iOS 简介页的页面：

- 导航栏左侧为圆形关闭按钮，标题为“Info”；
- 内容区最大宽度 860 px 并水平居中，依次为 160 px 高的大图标、项目名称（28 px，可
  换行）、种类（22 px 辅助文字）、主操作色“Open”胶囊按钮、“Information”小标题和
  白色圆角信息列表；符号链接不显示“Open”；
- 信息列表依次为 Kind、Size、Created、Modified、Where，左侧为辅助色标签，右侧为
  右对齐、可换行的值，行间以分隔线隔开；
- Size 显示“2,490,492 bytes (2.4 MB on disk)”，文件夹追加“, 12 items”（递归统计可见
  内容，超过统计上限时以“At least”开头）；文件系统没有记录创建时间时 Created 显示
  “--”；Where 以“Files”表示根目录，子目录为“Files/Documents”；
- “Open”沿用文件夹导航或文件预览规则；关闭返回原目录。

### 移动

“Move”打开参考 iOS 移动页的文件夹浏览页面：

- 导航栏左侧为圆形关闭按钮，中间为当前浏览文件夹名称和路径副标题，右侧为“Move”
  胶囊按钮；当前文件夹就是项目所在文件夹或位于被移动文件夹之内时，“Move”使用
  次级控件背景和辅助文字并禁用；
- 内容区顶部说明正在为哪个项目选择文件夹（“Choose a folder for “名称”.”，多个项目时为
  “Choose a folder for N items.”）；不在根目录时显示以导航强调色标注上一级
  名称的返回行；其后为列表行样式的子文件夹，被移动的文件夹本身以 40% 不透明度显示
  且不可进入；没有子文件夹时显示“No folders”；
- 移动多个项目时先检查全部项目，任一项目在目标处已有同名项目或文件夹将移入自身时
  不移动任何项目；
- 目标处已有同名项目或移动失败时停留在本页，并以危险色显示原因；成功后回到原目录。

### 重新命名、用 1 个项目新建文件夹与删除

- “Rename”使用与新建文件夹相同的 iOS 提示框，标题为“Rename”，输入框预填当前名称，
  按钮为“Cancel”和“Rename”；名称校验规则与新建文件夹相同，同名项目报错且保留输入；
- “New Folder with 1 Item”在当前目录创建“New Folder”（重名时追加编号），把项目移入
  其中，随即打开该文件夹的“Rename”提示框；取消时保留默认名称；
- “Delete”先显示确认提示框：标题“Delete “名称”?”（多个项目时为“Delete N Items?”），
  说明删除立即生效且无法撤销，按钮为次级控件色“Cancel”和危险色背景、白色文字的
  “Delete”；删除失败时在提示框内以危险色显示原因，提示框只保留尚未删除的项目。

### 更多操作

更多操作以 iOS 下拉菜单呈现：从右上角更多按钮处展开并覆盖该按钮，宽度不超过
340 px，高度超过可用空间时在菜单内滚动。菜单依次包含三组，组间以缩进分隔线隔开：

1. “Select”和“New Folder”；拷贝过项目后在其后增加“Paste”，把拷贝的全部项目粘贴到
   当前目录，同名时追加编号；任一被拷贝的项目已不存在时不粘贴，菜单保持打开并说明
   原因，同时不再提供“Paste”；
2. 显示方式“Icons”和“List”，当前方式前显示对勾；
3. 排序方式“Name”“Kind”“Date”“Size”，当前方式前显示对勾，并在其下以副标题
   显示“Ascending”或“Descending”。

每行依次为对勾列、可选的符号和文字。选择任一项后菜单关闭；点击菜单外区域关闭
菜单且不改变状态。菜单不使用暗色遮罩。项目操作只出现在上下文菜单中，不在更多
操作菜单中重复。

菜单末尾以单独的“Help”项打开帮助页。选择“Help”后菜单关闭；点击菜单外区域仍只关闭
菜单且不改变当前目录状态。

### 帮助页

从根目录或子目录导航栏右侧的更多操作菜单选择“Help”打开应用内帮助页。帮助属于
应用级页面，不依赖当前目录中的文件，也不在文件列表、文件上下文菜单或模拟文件根目录
中创建帮助文件。

- 帮助页导航栏左侧显示圆形关闭按钮，中间显示“Help”标题；页面内容放在可滚动容器内，
  不显示更多操作按钮；关闭按钮和帮助内容在竖屏、横屏及键盘出现时都必须可达；
- 内容按操作任务分组，至少说明浏览文件夹、打开文件和只读预览、搜索当前目录、图标与
  列表视图及排序、选择和批量操作，以及复制、移动、重命名、压缩、复制副本、新建文件夹
  和删除；每组使用清晰的小标题和简短步骤，不呈现应用不支持的共享、标签或收藏功能；
- 内容区最大宽度为 860 px 并水平居中，长文案由内容容器滚动，文字不得与导航栏重叠或
  超出页面；帮助文案使用 AppKit 字体和语义文字颜色，不使用独立的文件系统或 ViewModel
  状态；
- 帮助页获得键盘焦点后，方向键在关闭按钮与各操作分组之间移动焦点，并在内容边界继续
  滚动视口；`Tab` 和 `Shift-Tab` 也在这些焦点项之间移动，焦点分组自动滚动到可见区域；
- 关闭帮助页返回打开帮助前的页面，保留当前目录、显示方式、排序、搜索查询和内容滚动
  位置；帮助页自身的滚动位置在重新打开时从顶部开始；
- 帮助页只提供说明和关闭操作，不修改文件系统、选择状态或剪贴板，也不改变应用配置。

## 架构边界

依赖方向必须保持为：

```text
FilesView -> FilesViewModel -> FilesModel
```

- Model 执行文件系统操作、校验路径和维护页面业务状态，不包含 LVGL 类型或对象；
- ViewModel 提供展示 DTO、命令和 Subject，不拥有页面 widget；
- View 只访问 ViewModel，不直接调用 POSIX 文件 API，也不持有或修改 Model；
- 页面根对象必须创建在调用者传入的 `parent` 下，不假设它是活动 screen 或占满
  整个 display。

View 使用对象绑定的 observer 接收 Subject 更新。需要重建网格等复合内容时，
observer 只安排一次异步刷新，避免在 Subject 回调栈中删除触发回调的对象。销毁
页面时先移除或失效异步工作和非对象绑定资源，再删除根对象，最后清空缓存指针。

## 字体与图标

- 所有可见文本使用 `<cm0/typography.h>` 的 `lilygo_ui_font_get(size)`；
- 字体只能在 `lv_init()` 完成后取得，设置前必须检查返回指针非空；
- 页面不得引用 `lv_font_montserrat_*`，不得修改或释放 AppKit 返回的字体；
- 中英文和 Font Awesome 图标字形使用 AppKit 提供的同一 fallback 字体链；
- 本应用目前不需要私有字体，不得复制或重新打包 Inter、Source Han Sans CN 或
  Font Awesome 字体。
- 所有目录统一使用 iOS 风格的文件夹图标：由文件夹背板、标签页和带顶部高光的
  前板三个圆角矩形组成，不按目录名称区分图标；文件使用带折角的文档页图标。两种
  图标都由单个 LVGL 对象在绘制回调中完成，以控制大目录下的对象数量；图标只作
  装饰，不得拦截所在网格单元的点击；
- 返回和更多操作使用 Font Awesome 的 chevron-left 与 ellipsis-h 字形，关闭使用
  times；更多菜单使用 check-circle、folder-plus、paste、th-large、list-ul 和 check
  字形；上下文菜单使用 copy、folder、info-circle、pencil-alt、archive、clone、
  folder-plus 和 trash-alt 字形；选择工具栏使用 clone、folder、trash-alt 和 ellipsis-h，
  选择菜单使用 copy、folder-plus 和 archive 字形；列表文件夹箭头使用 chevron-right。

Files 页面使用有限且一致的文字层级：

| 字号 | 用途 |
| --- | --- |
| 14 px | 日期、文件大小、条目数量、路径副标题、类型标签和错误辅助信息 |
| 22 px | 文件名、正文、按钮和搜索框 |
| 28 px | 导航栏标题、提示框标题和预览文件名 |

缩小字号不是解决溢出的首选方式。应先调整 Flex/Grid 分配、允许换行或滚动，
并对文件名、路径等单行信息采用明确的截断策略。

## 响应式布局

页面主体必须使用 LVGL Flex 或 Grid，并依据页面父容器的实际可用宽高响应。
不得通过固定坐标堆叠主体内容，也不得复制 phone、desktop、横屏或竖屏页面。

- 连续尺寸变化由百分比、Flex/Grid、`LV_SIZE_CONTENT`、最小/最大尺寸和滚动容器
  自动处理；
- 只有导航方向、栏数或内容优先级发生结构变化时才使用断点；
- 断点只能依据父容器几何尺寸，不能依据 CPU、设备型号或命令行展示模式；
- 重复应用布局必须是幂等操作，不创建重复 observer，不重建页面，也不改变
  当前目录、搜索查询、输入内容、焦点或滚动位置；
- 网格单元和主要按钮具有稳定尺寸与足够的触控命中区域，圆形导航按钮为 56 px，
  动态图标或文字不得造成行高抖动；
- 长网格、长文本和键盘占用空间时由正确的内容区滚动，导航和必要操作保持可达；
- 导航栏固定在内容上方，只有搜索框、网格或文档滚动。若固定导航后内容区不足
  120 px（例如紧凑屏幕横置且键盘弹出），同一导航对象移入滚动区随内容滚动；选择模式
  的工具栏始终固定在内容下方，计算内容区高度时一并扣除；
- 网格列数按可用宽度计算，尺寸变化只更新单元宽度，不重建单元格；列表行始终占满
  内容宽度；
- 打开菜单和进入选择模式等在同一目录、同一显示方式下重建内容时，保持内容滚动位置；
  退出选择模式时目录内容回到顶部，确保搜索框完整可见；从预览、简介或移动页等页面
  回到同一目录内容时恢复离开时的滚动位置；
- 预览文档最大宽度 860 px 并水平居中。

竖屏和横屏使用相同的导航结构，宽容器只增加网格列数，不改变功能集合。界面不显示
iOS 中的麦克风按钮或“最近项目/共享/浏览”标签栏等没有对应功能的入口。页面不在
应用内部绘制设备状态栏或 Launcher 外壳。

## 对象命名与生命周期

渲染和交互测试依赖的对象必须使用稳定的 `lv_obj_set_name_static()` 语义名称。
名称描述角色而不是子对象位置，例如页面根对象、搜索输入、网格、预览正文、
新建文件夹输入、创建按钮和取消按钮。测试不得通过 `lv_obj_get_child(parent, n)`
猜测结构。

LVGL 父对象负责删除子对象。View 保存自己的顶层对象并提供可重复调用的销毁流程；
删除父对象后必须清空所有缓存子指针。事件 `user_data` 指向的 C++ 对象在事件注册
期间必须有效，ViewModel 的生命周期必须覆盖全部 Subject 绑定。

## 状态与错误

- 文件系统错误由 Model 产生结构化命令结果，ViewModel 转换并发布，View 只显示；
- 命令失败不得静默，也不得在失败后假装网格已更新；
- 目录刷新不能访问时显示错误状态，并保留可恢复的导航路径；
- 初始化失败时页面必须显示根目录错误，而不是空白画面；
- 用户输入只在成功完成对应操作或用户明确取消时清理。
