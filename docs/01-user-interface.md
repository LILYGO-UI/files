# LILYGO UI Files 界面规范

本文是 `lilygo-ui-files` 的项目级 UI 规范。修改页面、组件、布局、样式、文案、
字体或渲染测试时，必须同时遵守模板仓库中的 `docs/01-user-interface.md`；当本文
没有另行收窄产品行为时，以模板规范为准。

## 页面与用户流程

应用只有一个 Files 页面，由同一份业务状态呈现以下可达界面。尺寸变化只重新
应用布局，不得重建 ViewModel 或清空用户状态。

### 根目录

- 显示“Files”标题、当前根目录的容量摘要、搜索入口、文件列表和更多操作入口；
- 文件夹排在文件之前，名称比较不区分大小写；
- 隐藏项目不显示；空目录和目录读取失败必须显示明确状态；
- 点击普通文件夹进入该目录，点击文件进入只读预览。

### 子目录

- 显示返回操作、当前目录名称、相对根目录的路径、搜索入口和文件列表；
- 返回操作逐级回到父目录，但不能越过配置的文件根目录；
- 很长的目录名和路径必须换行、截断或在自己的区域内滚动，不得挤压主要操作。

### 搜索

- 搜索范围仅为当前目录，不递归扫描；
- 输入变化通过 ViewModel 更新查询和结果数量；
- 点击搜索结果沿用文件夹导航或文件预览规则；
- 无结果时显示空状态，搜索文字在横竖屏切换后保持不变；
- 屏幕键盘出现时，输入框、结果列表和退出搜索的操作必须仍然可达。

### 文本预览

- 预览是只读界面，显示文件名、文件信息和文本内容；
- 文档容器使用 `LV_SIZE_CONTENT` 或等价的内容驱动尺寸，长文本由外层容器滚动；
- 预览最多显示 8 KiB，截断时必须显示 `[Preview truncated]`；
- 不支持的文件类型显示明确说明，不呈现不存在的编辑、分享或文件管理操作；
- 文件名、元数据和正文均不得与导航区重叠或越出页面。

### 新建文件夹

- 从“更多操作”进入模态框，输入目标文件夹名称后创建在当前目录；
- 模态框只提供“取消”和“创建”两项明确操作；
- 空名称、`.`、`..`、包含 `/`、路径过长、重名或权限错误必须保留当前输入并
  显示可理解的错误；
- 创建成功后关闭模态框、刷新当前列表，并保持用户仍位于原目录。

### 更多操作

更多操作面板当前只包含“New Folder”和“Cancel”。复制、重命名、移动、压缩、
删除、选择项目、排序方式和显示方式尚未实现，不得为这些能力展示无效入口。

## 架构边界

依赖方向必须保持为：

```text
FilesView -> FilesViewModel -> FilesModel
```

- Model 执行文件系统操作、校验路径和维护页面业务状态，不包含 LVGL 类型或对象；
- ViewModel 提供展示 DTO、命令和 Subject，不拥有页面 widget；
- View 只访问 ViewModel，不直接调用 POSIX 文件 API，也不持有或修改 Model；
- 页面根对象必须创建在调用者传入的 `parent` 下，不假设它是活动 screen 或占满
  整个 display。

View 使用对象绑定的 observer 接收 Subject 更新。需要重建列表等复合内容时，
observer 只安排一次异步刷新，避免在 Subject 回调栈中删除触发回调的对象。销毁
页面时先移除或失效异步工作和非对象绑定资源，再删除根对象，最后清空缓存指针。

## 语义颜色

页面应复用 `src/components/components.hpp` 中的语义颜色，不在 View 中重复定义
同一用途的色值。

| 角色 | 用途 | 色值 | 透明度 |
| --- | --- | --- | --- |
| 页面背景 | 页面根容器与滚动背景 | `#F2F2F7` | `100%` |
| 容器背景 | 列表、面板和模态框 | `#FFFFFF` | `100%` |
| 容器标题 | 页面和区块标题 | `#1A1A1A` | `100%` |
| 正文 | 文件名、正文和主要数值 | `#000000` | `100%` |
| 边框 | 分隔线和容器边界 | `#D8DDE3` | `100%` |
| 主操作 | “Create”等确认按钮 | `#20262D` | `100%` |
| 主操作前景 | 主操作按钮上的文字和图标 | `#FFFFFF` | `100%` |
| 导航强调 | 返回、搜索和导航图标 | `#007AFF` | `100%` |
| 辅助文字 | 路径、文件大小和容量说明 | `#8E8E93` | `100%` |
| 占位文字 | 搜索输入提示和弱提示图标 | `#7C7C80` | `100%` |
| 选中背景 | 文件类型标签等轻量强调背景 | `#EAF4FF` | `100%` |
| 控件背景 | 屏幕键盘等输入控件背景 | `#E3E3E8` | `100%` |
| 次级控件 | 取消按钮和次级圆形按钮背景 | `#E5E5EA` | `100%` |
| 错误/危险 | 错误信息 | `#FF3B30` | `100%` |
| 下载强调 | 下载目录图标 | `#30B0C7` | `100%` |
| 模态遮罩 | 更多面板和新建文件夹对话框的背景遮罩 | `#000000` | `30%` |

新增颜色必须先定义语义角色、场景、色值和透明度。不得使用渐变替代语义颜色，
也不得把导航蓝色作为主确认按钮背景。

## 字体与图标

- 所有可见文本使用 `<cm0/typography.h>` 的 `lilygo_ui_font_get(size)`；
- 字体只能在 `lv_init()` 完成后取得，设置前必须检查返回指针非空；
- 页面不得引用 `lv_font_montserrat_*`，不得修改或释放 AppKit 返回的字体；
- 中英文和 Font Awesome 图标字形使用 AppKit 提供的同一 fallback 字体链；
- 本应用目前不需要私有字体，不得复制或重新打包 Inter、Source Han Sans CN 或
  Font Awesome 字体。

Files 页面使用有限且一致的文字层级：

| 字号 | 用途 |
| --- | --- |
| 14 px | 文件大小、路径、容量和错误辅助信息 |
| 22 px | 正文、按钮、搜索框和列表项 |
| 28 px | 模态框标题、预览文件名等小标题 |
| 36 px | 根目录页面标题 |

缩小字号不是解决溢出的首选方式。应先调整 Flex/Grid 分配、允许换行或滚动，
并对文件名、路径等单行信息采用明确的截断策略。

## 响应式布局

页面主体必须使用 LVGL Flex 或 Grid，并依据页面父容器的实际可用宽高响应。
不得通过固定坐标堆叠主体内容，也不得复制 phone、desktop、横屏或竖屏页面。

- 连续尺寸变化由百分比、Flex/Grid、`LV_SIZE_CONTENT`、最小/最大尺寸和滚动容器
  自动处理；
- 只有导航方向、栏数或内容优先级发生结构变化时才使用断点；
- 断点只能依据父容器几何尺寸，不能依据 CPU、设备型号或命令行展示模式；
- 重复应用布局必须是幂等操作，不创建重复 observer，不重建页面，也不改变
  当前目录、搜索查询、输入内容、焦点或滚动位置；
- 列表项和主要按钮具有稳定尺寸与足够的触控命中区域，动态图标或文字不得造成
  行高抖动；
- 长列表、长文本和键盘占用空间时由正确的内容区滚动，导航和必要操作保持可达。

竖屏可采用单列、纵向信息层级；横屏或宽容器可以调整内容宽度与栏间关系，但不能
改变功能集合。页面不在应用内部绘制设备状态栏或 Launcher 外壳。

## 对象命名与生命周期

渲染和交互测试依赖的对象必须使用稳定的 `lv_obj_set_name_static()` 语义名称。
名称描述角色而不是子对象位置，例如页面根对象、搜索输入、列表、预览正文、
新建文件夹输入、创建按钮和取消按钮。测试不得通过 `lv_obj_get_child(parent, n)`
猜测结构。

LVGL 父对象负责删除子对象。View 保存自己的顶层对象并提供可重复调用的销毁流程；
删除父对象后必须清空所有缓存子指针。事件 `user_data` 指向的 C++ 对象在事件注册
期间必须有效，ViewModel 的生命周期必须覆盖全部 Subject 绑定。

## 状态与错误

- 文件系统错误由 Model 产生结构化命令结果，ViewModel 转换并发布，View 只显示；
- 命令失败不得静默，也不得在失败后假装列表已更新；
- 目录刷新不能访问时显示错误状态，并保留可恢复的导航路径；
- 初始化失败时页面必须显示根目录错误，而不是空白画面；
- 用户输入只在成功完成对应操作或用户明确取消时清理。

## 验收矩阵

所有可达界面至少在 `568x1232` 和 `1232x568` 下完成渲染和交互检查：

| 界面 | 必查内容 |
| --- | --- |
| 根目录 | 容量、搜索入口、空/非空列表、更多操作 |
| 子目录 | 返回、长路径、空/非空列表 |
| 搜索 | 输入、零/多个结果、键盘、打开结果 |
| 文本预览 | 短文本、超过 8 KiB 文本、长文件名、滚动 |
| 非文本预览 | 不支持说明、无伪功能按钮 |
| 新建文件夹 | 默认值、校验错误、取消、创建成功 |
| 更多操作 | 仅新建文件夹和取消，面板内容可达 |

还必须执行一次同一 View 的动态尺寸变化，确认目录、查询、输入、焦点和滚动位置
保持。`320x568` 与 `1024x768` 可用于额外边界检查。视觉检查需要确认文字无缺字、
错误 fallback、重叠或裁切，颜色角色正确，主要操作可见且可达。

对应的自动化测试至少包括：不初始化 LVGL 的 Model 测试、初始化 LVGL 后的
ViewModel/Subject 测试，以及使用语义对象名称的无头渲染与交互测试。测试通过
不能替代横竖屏截图的人工检查。
